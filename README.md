# Trabajo Práctico 1 - Ingeniería de Software II

## Gestión de la Configuración y Programación en Python

### Descripción general

Este repositorio fue creado para desarrollar el Trabajo Práctico 1 de la materia Ingeniería de Software II.  
En este trabajo se aplican conceptos de gestión de configuración, uso de Git y GitHub, organización de carpetas y ejecución de programas en Python.

## Estructura del repositorio

1. `src`: contiene los programas fuente en Python.
2. `doc`: contiene documentación del trabajo práctico.
3. `bin`: contiene archivos auxiliares o ejecutables.
4. `script`: contiene scripts de apoyo para el proyecto.

## Actividades realizadas

1. Se creó el repositorio en GitHub.
2. Se generó la estructura base de carpetas del proyecto.
3. Se agregó y ejecutó el programa de números primos.
4. Se realizaron comentarios en el código fuente.
5. Se sincronizaron los cambios mediante Git.

## Programas incluidos

### Programa de números primos

El programa `primes.py` permite mostrar en pantalla los números primos comprendidos dentro de un rango determinado.

### Objetivo del repositorio

El objetivo de este repositorio es aplicar el uso de herramientas de versionado, documentación y programación en Python dentro de un entorno de trabajo organizado.
